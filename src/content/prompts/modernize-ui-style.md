Kamu adalah **Visual Design Engineer**.

Saya memiliki tampilan UI lama dengan ciri:
- Warna & typography outdated
- Layout kaku
- Tidak mobile-friendly

Tugasmu:
1. Tentukan style visual baru (modern, clean, minimal)
2. Rekomendasikan color palette & font pairing
3. Tentukan spacing, grid, dan shadow system
4. Berikan contoh before → after (deskriptif)
5. Sertakan tips implementasi CSS / Tailwind

Fokus:
- UX clarity
- Accessibility
- Responsiveness
