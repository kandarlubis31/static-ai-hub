INPUT DATA:
- Account Niche: [NICHE]
- Target Audience: [DESKRIPSI]
- Current Follower Count: [JUMLAH]
- Average Engagement Rate: [PERSEN]
- Growth Stage: [stage: early, growth, mature, viral]

HASHTAG RESEARCH & STRATEGY:

1. HASHTAG CATEGORIZATION
   Kelompokkan hashtags menjadi 4 tier berdasarkan volume & competition:
   
   Tier 1 - Mega Hashtags (500K+ posts)
   - Use 2-3 hashtags
   - Generic, high volume, low conversion
   - Purpose: reach maximum audience
   
   Tier 2 - Popular Hashtags (50K-500K posts)
   - Use 4-5 hashtags
   - Balanced volume dan competition
   - Purpose: qualified traffic
   
   Tier 3 - Niche Hashtags (10K-50K posts)
   - Use 5-6 hashtags
   - Specific audience, better engagement
   - Purpose: target ideal customer profile
   
   Tier 4 - Micro Hashtags (1K-10K posts)
   - Use 4-5 hashtags
   - Ultra-specific, high engagement rate
   - Purpose: community building & authority

2. HASHTAG VARIATION SETS
   Buat 3 hashtag sets (A, B, C) dengan berbeda angle:
   Set A: Product/Service focused
   Set B: Lifestyle/Values focused
   Set C: Problem-Solution focused

3. HASHTAG ROTATION SYSTEM
   - 5 permanent hashtags (always use)
   - 15-20 rotating hashtags per post
   - Seasonal hashtags untuk campaign spesifik
   - Trending hashtags strategy (if applicable)

4. HASHTAG TESTING PLAN
   - Week 1-2: Test Set A, track analytics
   - Week 3-4: Test Set B, measure performance
   - Week 5-6: Test Set C, compare results
   - Optimize based pada best performers

5. BANNED & RISKY HASHTAGS
   - List hashtags to AVOID (shadowban risk)
   - Hashtags yang overused di niche
   - Hashtags dengan poor engagement rate

OUTPUT:
- Complete hashtag lists untuk setiap tier
- 3 variation sets ready to use
- Implementation schedule
- Tracking spreadsheet template
- Monthly optimization checklist
