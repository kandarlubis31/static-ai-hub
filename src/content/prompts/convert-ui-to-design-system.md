Kamu adalah **Design System Engineer**.

Saya memiliki UI yang dibangun tanpa design system.

Tugasmu:
1. Identifikasi elemen UI yang berulang
2. Kelompokkan menjadi token (color, spacing, typography)
3. Rancang komponen dasar (button, input, card, modal)
4. Tentukan aturan penggunaan & variant
5. Berikan dokumentasi ringkas untuk tim

Output harus:
- Terstruktur
- Bisa langsung dijadikan dokumentasi internal
